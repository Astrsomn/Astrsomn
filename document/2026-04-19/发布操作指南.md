# Astrsomn 发布操作指南

## 环境准备

### 1. GitHub Personal Access Token 配置

1. 访问 GitHub Developer Settings：https://github.com/settings/tokens
2. 生成 Classic Token，勾选 `repo` 和 `packages` 权限
3. 配置 Maven settings.xml（通常位于 `~/.m2/settings.xml`）：

```xml
<settings>
  <servers>
    <server>
      <id>github</id>
      <username>YOUR_GITHUB_USERNAME</username>
      <password>YOUR_PERSONAL_ACCESS_TOKEN</password>
    </server>
  </servers>
</settings>
```

### 2. 项目 pom.xml 配置

确保父 pom.xml 包含 GitHub Packages distributionManagement：

```xml
<distributionManagement>
  <repository>
    <id>github</id>
    <name>GitHub Astrsomn Apache Maven Packages</name>
    <url>https://maven.pkg.github.com/Astrsomn/Astrsomn</url>
  </repository>
</distributionManagement>
```

## 发布流程

### 一、Release 操作

Release 操作用于正式发布版本到 GitHub Releases 页面。

#### 步骤 1：确认发布版本

```bash
# 查看当前版本
git checkout release/0.1.0-alpha.1
git status
git log --oneline -5
```

#### 步骤 2：创建 Release Tag

```bash
# 创建带注释的标签
git tag -a v0.1.0-alpha.1 -m "Release version 0.1.0-alpha.1"

# 推送标签到远程
git push github v0.1.0-alpha.1
```

#### 步骤 3：创建 GitHub Release

```bash
# 使用 GitHub CLI 创建 Release
gh release create v0.1.0-alpha.1 \
  --title "Astrsomn v0.1.0-alpha.1" \
  --notes "Release version 0.1.0-alpha.1

## 主要内容
- 初始版本发布

## 模块
- astrsomn-spring-boot-starter
- astrsomn-providers
- astrsomn-vector" \
  --generate-notes
```

或通过 GitHub Web UI：
1. 访问 https://github.com/Astrsomn/Astrsomn/releases/new
2. 选择 tag `v0.1.0-alpha.1`
3. 填写版本标题和发布说明
4. 点击 "Publish release"

---

### 二、Tag 操作

Tag 用于标记代码仓库的关键节点。

#### 创建本地 Tag

```bash
# 轻量级标签
git tag v0.1.0-alpha.1

# 带注释的标签（推荐）
git tag -a v0.1.0-alpha.1 -m "版本 0.1.0-alpha.1 发布"
```

#### 查看 Tag 列表

```bash
# 查看所有标签
git tag

# 查看标签详细信息
git show v0.1.0-alpha.1
```

#### 删除 Tag

```bash
# 删除本地标签
git tag -d v0.1.0-alpha.1

# 删除远程标签
git push github --delete v0.1.0-alpha.1
```

#### 推送 Tag 到远程

```bash
# 推送单个标签
git push github v0.1.0-alpha.1

# 推送所有标签
git push github --tags
```

### 三、Package 操作

Package 操作将 Maven 构件发布到 GitHub Packages。

#### 完整发布命令

```bash
# 清理并发布到 GitHub Packages
mvn clean deploy -P github

# 仅发布指定模块
mvn clean deploy -P github -pl astrsomn-spring-boot-starter,astrsomn-providers,astrsomn-vector -am
```

#### 分步操作

```bash
# 1. 验证构建
mvn clean verify

# 2. 安装到本地仓库（测试用）
mvn clean install

# 3. 发布到 GitHub Packages
mvn clean deploy -P github
```

#### 发布特定模块组合

```bash
# 发布核心模块
mvn clean deploy -P github -pl astrsomn-spring-boot-starter -am

# 发布 providers 模块
mvn clean deploy -P github -pl astrsomn-providers -am

# 发布 vector 模块
mvn clean deploy -P github -pl astrsomn-vector -am
```

### 四、依赖引用

发布后，其他项目可通过 Maven 依赖引用：

```xml
<dependencies>
  <!-- Spring Boot Starter -->
  <dependency>
    <groupId>org.astrsomn</groupId>
    <artifactId>astrsomn-spring-boot-starter</artifactId>
    <version>0.1.0-alpha.1</version>
  </dependency>

  <!-- Providers -->
  <dependency>
    <groupId>org.astrsomn</groupId>
    <artifactId>astrsomn-providers</artifactId>
    <version>0.1.0-alpha.1</version>
    <type>pom</type>
  </dependency>

  <!-- Vector -->
  <dependency>
    <groupId>org.astrsomn</groupId>
    <artifactId>astrsomn-vector</artifactId>
    <version>0.1.0-alpha.1</version>
    <type>pom</type>
  </dependency>
</dependencies>
```

settings.xml 需要配置 GitHub Packages 下载权限：

```xml
<settings>
  <servers>
    <server>
      <id>github</id>
      <username>YOUR_GITHUB_USERNAME</username>
      <password>YOUR_PERSONAL_ACCESS_TOKEN</password>
    </server>
  </servers>
</settings>
```

## 一键发布脚本

创建 `release.sh`：

```bash
#!/bin/bash
VERSION=${1:-"0.1.0-alpha.1"}
TAG="v${VERSION}"

echo "开始发布 Astrsomn ${VERSION}..."

# 1. 创建标签
git tag -a ${TAG} -m "Release version ${VERSION}"

# 2. 推送标签
git push github ${TAG}

# 3. 构建并发布到 GitHub Packages
mvn clean deploy -P github

# 4. 创建 GitHub Release
gh release create ${TAG} \
  --title "Astrsomn ${TAG}" \
  --notes "Release version ${VERSION}" \
  --generate-notes

echo "发布完成！"
```

使用方法：
```bash
chmod +x release.sh
./release.sh 0.1.0-alpha.1
```

## 注意事项

1. **版本号规范**：遵循语义化版本 `主版本.次版本.修订号-预发布标签`
2. **Tag 命名**：建议使用 `v` 前缀，如 `v0.1.0-alpha.1`
3. **发布前检查**：
   - 确保代码已提交且测试通过
   - 确认版本号已更新
   - 检查 GitHub Token 权限
4. **GitHub Packages 访问**：首次下载可能需要登录 GitHub 账号
5. **模块依赖顺序**：astrsomn-providers 和 astrsomn-vector 依赖 astrsomn-core，发布时注意顺序

## 故障排查

| 问题 | 解决方案 |
|------|----------|
| 401 Unauthorized | 检查 Maven settings.xml 中的 GitHub Token |
| 403 Forbidden | 确保 Token 有 packages:write 权限 |
| 模块找不到 | 添加 `-am` 参数同时构建依赖模块 |
| Tag 已存在 | 先删除本地和远程 tag，再重新创建推送 |
