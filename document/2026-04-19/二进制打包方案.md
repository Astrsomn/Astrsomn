## 二、Linux tar.gz 包方案

### 2.1 目录结构

```
astrsomn-linux-x.x.x.tar.gz
├── bin/
│   └── astrsomn          # 启动脚本
├── config/
│   └── application.yml   # 配置文件
├── lib/
│   └── astrsomn-server.jar  # 可执行 JAR
└── logs/                 # 日志目录（运行时创建）
```

### 2.2 打包脚本 (build-linux.sh)

```bash
#!/bin/bash
set -e

VERSION=${1:-"0.1.0-alpha.1"}
PACKAGE_NAME="astrsomn-linux-${VERSION}"

echo "开始构建 Linux 版本..."

# 1. 清理旧构建
rm -rf build/linux
mkdir -p build/linux

# 2. 构建前端
cd astrsomn-ui
npm install
npm run build
cd ..

# 3. 构建后端
mvn clean package -DskipTests -pl astrsomn-server -am

# 4. 复制文件到构建目录
mkdir -p build/linux/${PACKAGE_NAME}/bin
mkdir -p build/linux/${PACKAGE_NAME}/config
mkdir -p build/linux/${PACKAGE_NAME}/lib
mkdir -p build/linux/${PACKAGE_NAME}/logs

# 复制启动脚本
cp scripts/astrsomn.sh build/linux/${PACKAGE_NAME}/bin/astrsomn
chmod +x build/linux/${PACKAGE_NAME}/bin/astrsomn

# 复制 JAR
cp astrsomn-server/target/astrsomn-server-${VERSION}.jar \
   build/linux/${PACKAGE_NAME}/lib/astrsomn-server.jar

# 复制默认配置
cp astrsomn-server/src/main/resources/application.yml \
   build/linux/${PACKAGE_NAME}/config/application.yml

# 5. 创建 tar.gz 包
cd build/linux
tar -czvf ${PACKAGE_NAME}.tar.gz ${PACKAGE_NAME}
cd ../..

echo "Linux 构建完成: build/linux/${PACKAGE_NAME}.tar.gz"
```

### 2.3 启动脚本 (scripts/astrsomn.sh)

```bash
#!/bin/bash

# Astrsomn 启动脚本

APP_HOME="$(cd "$(dirname "$0")/.." && pwd)"
APP_NAME="Astrsomn"
JAR_FILE="$APP_HOME/lib/astrsomn-server.jar"
CONFIG_FILE="$APP_HOME/config/application.yml"
LOG_DIR="$APP_HOME/logs"

# 创建日志目录
mkdir -p "$LOG_DIR"

# JVM 参数
JAVA_OPTS="-Xms512m -Xmx2g -XX:+UseG1GC"

# 启动应用
echo "启动 $APP_NAME..."
echo "配置文件: $CONFIG_FILE"
echo "日志目录: $LOG_DIR"

java $JAVA_OPTS -jar "$JAR_FILE" --spring.config.location="$CONFIG_FILE" \
    >> "$LOG_DIR/astrsomn.log" 2>&1 &

echo $! > "$APP_HOME/app.pid"

echo "$APP_NAME 已启动 (PID: $(cat $APP_HOME/app.pid))"
echo "日志文件: $LOG_DIR/astrsomn.log"
```

### 2.4 使用方式

```bash
# 解压
tar -xzvf astrsomn-linux-0.1.0-alpha.1.tar.gz

# 进入目录
cd astrsomn-linux-0.1.0-alpha.1

# 编辑配置文件
vim config/application.yml

# 启动
./bin/astrsomn

# 停止
kill $(cat app.pid)
```

## 三、Windows exe 安装程序方案

### 3.1 技术选型

推荐使用 **NSIS** (Nullsoft Scriptable Install System) 或 **Inno Setup**

**推荐使用 Inno Setup**，原因：
- 免费开源
- Pascal 脚本，学习成本低
- 支持自定义界面
- 输出单文件 exe 安装程序

### 3.5 Windows 安装程序构建脚本 (build-windows.ps1)

```powershell
$VERSION = "0.1.0-alpha.1"
$OUTPUT_DIR = "build\windows"

Write-Host "开始构建 Windows 安装程序..."

# 1. 清理并创建目录
if (!(Test-Path $OUTPUT_DIR)) {
    New-Item -ItemType Directory -Path $OUTPUT_DIR -Force
}

# 2. 构建前端
Set-Location "astrsomn-ui"
npm install
npm run build
Set-Location ".."

# 3. 构建后端
mvn clean package -DskipTests -pl astrsomn-server -am

# 4. 复制文件到临时目录
$BUILD_DIR = "$OUTPUT_DIR\build"
if (Test-Path $BUILD_DIR) {
    Remove-Item $BUILD_DIR -Recurse -Force
}
New-Item -ItemType Directory -Path "$BUILD_DIR\lib" -Force
New-Item -ItemType Directory -Path "$BUILD_DIR\config" -Force

Copy-Item "astrsomn-server\target\astrsomn-server-${VERSION}.jar" "$BUILD_DIR\lib\"
Copy-Item "astrsomn-server\src\main\resources\application.yml" "$BUILD_DIR\config\"

# 5. 使用 Inno Setup 编译
$ISCC = "C:\Program Files (x86)\Inno Setup 6\ISCC.exe"
if (Test-Path $ISCC) {
    & $ISCC "scripts\setup.iss"
    Write-Host "安装程序已生成: $OUTPUT_DIR\astrsomn-windows-${VERSION}-setup.exe"
} else {
    Write-Host "未找到 Inno Setup，请手动编译 setup.iss"
    Write-Host "或从 https://jrsoftware.org/isdl.php 下载安装"
}

Write-Host "Windows 构建完成"
```

### 4.4 Windows 安装程序配置生成

在 Windows 安装时，用户的表单数据需要转换为 `application.yml`：

```python
# scripts/generate_config.py (Python 辅助脚本)
import yaml
import os
import sys

def generate_application_yml(db_config, server_config):
    """根据安装配置生成 application.yml"""

    config = {
        'server': {
            'port': int(server_config['port']),
            'servlet': {
                'context-path': server_config.get('contextPath', '/')
            }
        },
        'spring': {
            'application': {
                'name': 'Astrsomn'
            },
            'datasource': {
                'driver-class-name': db_config['driverClass'],
                'url': db_config['url'],
                'username': db_config['username'],
                'password': db_config['password']
            }
        },
        # ... 其他配置
    }

    with open('config/application.yml', 'w', encoding='utf-8') as f:
        yaml.dump(config, f, allow_unicode=True, default_flow_style=False)

if __name__ == '__main__':
    # 从命令行参数读取配置
    db_type = sys.argv[1]  # mysql 或 oracle
    # ... 解析其他参数
    generate_application_yml(...)
```

### 6.3 运行时检查

启动脚本应包含运行环境检查：

```bash
#!/bin/bash

# 检查 Java
if ! command -v java &> /dev/null; then
    echo "错误: 未找到 Java，请先安装 Java 17+"
    echo "下载地址: https://adoptium.net/"
    exit 1
fi

# 检查 Java 版本
JAVA_VERSION=$(java -version 2>&1 | head -n 1 | cut -d'"' -f2 | cut -d'.' -f1)
if [ "$JAVA_VERSION" -lt 17 ]; then
    echo "错误: Java 版本需要 17+，当前版本: $JAVA_VERSION"
    exit 1
fi

echo "环境检查通过"
```
