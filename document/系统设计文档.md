# Astrsomn 系统设计文档

## 1. 项目概述

### 1.1 项目简介
Astrsomn 是一个基于 LangChain4j 的企业级 AI 智能体平台，提供多模型支持、智能对话、工具调用、知识库检索等核心功能。系统采用模块化架构，支持灵活配置和扩展。

### 1.2 核心特性
- 多模型支持：集成 OpenAI、通义千问、智谱 AI、百度文心等多个 AI 模型提供商
- 智能对话：支持流式和非流式对话，具备上下文记忆能力
- 工具调用：支持 MCP (Model Context Protocol) 和自定义工具
- 知识库集成：支持向量数据库检索增强生成 (RAG)
- 灵活配置：基于数据库的动态配置，无需重启服务
- 微服务架构：基于 Spring Cloud Alibaba 的分布式架构

### 2.2 模块划分

#### 2.2.1 astrsomn-core (核心模块)
**职责**：定义核心业务实体、枚举、异常处理和 LangChain4j 集成接口

**主要包结构**：
- `org.astrsomn.core.common.base`：基础类（Controller、Entity、Response 等）
- `org.astrsomn.core.common.constant`：枚举定义（AI 模型、Agent、工具等）
- `org.astrsomn.core.common.entity`：实体类定义
- `org.astrsomn.core.common.exception`：全局异常处理
- `org.astrsomn.core.common.mapper`：MyBatis Mapper 接口
- `org.astrsomn.core.common.langchain`：LangChain4j 集成

#### 2.2.2 astrsomn-spring-boot-starter (启动器模块)
**职责**：提供 Spring Boot 自动配置和组件装配

**主要包结构**：
- `org.astrsomn.starter.config`：自动配置类
- `org.astrsomn.starter.langchain`：LangChain4j 工厂和组件
  - `factory`：模型工厂（ChatModel、StreamModel）
  - `mcp`：MCP 工具提供者
  - `memory`：记忆管理
  - `tool`：工具提供者
  - `stream`：流式处理

#### 2.2.3 astrsomn-server (服务模块)
**职责**：提供 REST API 服务，整合各模块功能

**主要功能**：
- Web 服务入口
- 业务逻辑处理
- 数据持久化
- 外部服务调用

#### 2.2.4 astrsomn-ui (前端模块)
**职责**：用户界面交互

## 3. 核心功能设计

### 3.1 AI Agent 管理

#### 3.1.1 Agent 实体设计
**表名**：AI_AGENT

**核心字段**：
- `name`：Agent 名称
- `description`：Agent 描述
- `model_id`：关联的 AI 模型 ID
- `prompt_uuid`：系统提示词 UUID
- `config_params`：运行时配置参数（JSON 格式）
- `status`：状态（ENABLED/DISABLED）
- `knowledge_base_ids`：关联的知识库 ID 列表
- `tool_ids`：关联的工具 ID 列表
- `mcp_ids`：关联的 MCP 服务器 ID 列表
- `memory_mode`：记忆模式（NONE/SLIDING_WINDOW/VECTOR）
- `memory_window_size`：记忆窗口大小
- `max_token`：最大令牌数
- `temperature`：温度参数
- `enable_stream`：是否启用流式输出

#### 3.1.2 Agent 构建流程
```
1. 从数据库加载 Agent 配置
2. 根据 model_id 创建 ChatModel
3. 根据 prompt_uuid 加载系统提示词
4. 配置记忆提供者（基于 memory_mode）
5. 配置知识库检索器（基于 knowledge_base_ids）
6. 配置 MCP 工具（基于 mcp_ids）
7. 配置本地工具（基于 tool_ids）
8. 构建 AstrsomnChatAssistant 实例
```

#### 3.2.1 模型实体设计
**表名**：AI_MODEL_CONFIG

**核心字段**：

- `api_secret`：API 密钥

- `model_params`：模型参数（JSON 格式）
- `status`：状态（ENABLED/DISABLED）
- `response_limit`：响应限制
- `random_index`：随机性参数
- `top_variance`：Top-P 参数
- `capabilities`：能力分类（JSON 格式）

#### 3.2.2 支持的模型提供商

- Alibaba (通义千问)
- ZhiPu (GLM 系列)

- Baidu (文心一言)
- Baichuan
- MiniMax

**核心字段**：

### 3.4 提示词管理

#### 3.4.1 提示词实体设计
**表名**：AI_PROMPT

**核心字段**：
- `prompt_key`：提示词 UUID（多个版本共享同一 UUID）
- `prompt_title`：提示词标题
- `prompt_content`：提示词内容
- `scene`：场景分类
- `enabled_flag`：启用状态
- `version`：版本号

#### 3.4.2 提示词版本管理
- 通过 `prompt_key` 关联多个版本
- 支持历史版本回溯
- 版本号递增管理

### 3.5 对话管理

#### 3.5.1 对话实体设计
**表名**：AI_CONVERSATION

**核心字段**：
- `conversation_id`：对话 ID
- `agent_id`：关联的 Agent ID
- `user_id`：用户 ID
- `messages`：对话消息（JSON 格式）
- `created_at`：创建时间
- `updated_at`：更新时间

#### 3.5.2 记忆模式
- **NONE**：无记忆
- **SLIDING_WINDOW**：滑动窗口记忆
- **VECTOR**：向量记忆（基于向量数据库）

### 3.6 知识库管理

#### 3.6.1 模板实体设计
**表名**：AI_TEMPLATE

**核心字段**：
- `template_name`：模板名称
- `template_key`：模板标识
- `description`：描述
- `content`：模板内容
- `type`：类型
- `enable_flag`：启用状态

#### 3.6.2 向量检索
- 支持多种向量数据库（Qdrant、Chroma）
- 嵌入模型支持（all-minilm-l6-v2、Jina 等）
- 动态维度匹配
